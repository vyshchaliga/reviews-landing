# Вихідники графіки

Ця тека не потрапляє на сайт: Vercel публікує лише `public/`.
Тут лежать оригінали, з яких зібрані файли в `public/assets/img/`,
щоб їх можна було перезібрати, не шукаючи вихідники заново.

| Файл | Що це | Що з нього зроблено |
|---|---|---|
| `team-original.jpg` | фото потоку з заходу, без обробки | `public/assets/img/team.webp` — кадр 780×437 зі згасанням країв, запеченим в альфу |
| `team-gradient.png` | те саме фото цілком, зі згасанням по всіх чотирьох краях | версія для Figma, на сайті не використовується |
| `sasha-studio-original.jpg` | студійний портрет на білому | `public/assets/img/sasha-studio.webp` — вирізаний із фону, низ торса і плечі розчиняються в прозорість |
| `arrow-original.webp` | золота стрілка, надана Дмитром | була `public/assets/img/arrow.webp` (знята з лендінга 28.10) |

Згасання запікається в альфу самого файлу, а не маскою в CSS: так воно
лягає на стелю й підлогу кадру, а не ріже людям голови й руки.
