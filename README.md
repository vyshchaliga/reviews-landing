# reviews-landing

Стіна відгуків «Вища Ліга»: **reviews.vyschaliga.com**.
Це соціальний доказ, а не продаючий ленд: люди приходять з ретаргету, розсилок і дожиму після діагностики, гортають відгуки й тиснуть єдину кнопку **«Хочу у Вищу Лігу»** (веде на `https://vyschaliga.com/main`).

Статичний сайт без фреймворків і без збірки: HTML, CSS і JS у папці `public/`. Деплой: Vercel. Відео: Bunny Stream.

## Як це працює

• Усі відгуки лежать в одній таблиці `public/data/reviews.csv`. Порядок рядків = порядок на стіні (зверху вниз, зліва направо по колонках).
• Скріни лежать у репозиторії (`public/assets/shots/`). Відео в репозиторії **не** лежать: вони в Bunny Stream, у таблиці тільки їхній ID.
• Мова: українська за замовчуванням, російська, якщо мова браузера російська. У правому верхньому куті є перемикач UA | RU. Вручну: `?lang=ru`.
• Закріплена кнопка з'являється, коли відвідувач доскролив до 5-го відгука (число змінюється в `public/config.js`).
• На першому й останньому екрані кнопки немає (так задумано).

## Таблиця `public/data/reviews.csv`

| Колонка | Що це |
|---|---|
| `type` | `video` або `shot` (скрін) |
| `media` | для відео: ID відео з Bunny (GUID); для скріна: назва файлу з `public/assets/shots/` |
| `w`, `h` | розміри скріна в пікселях (заповнюються автоматично) |
| `name_ua`, `name_ru` | імʼя та прізвище українською й російською |
| `niche_ua`, `niche_ru` | ніша; на сайті виводиться з великої літери |
| `ring` | тільки для скрінів: червона рамка навколо жорсткого результату, у відсотках від скріна: `ліво верх ширина висота`, наприклад `8 13 85 8`. Порожньо = без рамки |

Підпис під відгуком на сайті: **Імʼя Прізвище | Ніша**.
Відео з порожнім `media` на сайті не показуються (це місце під відео, яке ще не завантажили).

## Як додати відгук (для людини або для Claude Code)

Щоразу після змін: `npm run validate`, далі `git add -A && git commit && git push`. Vercel сам перезбере сайт за 1–2 хвилини. Якщо таблиця зламана, деплой зупиниться з поясненням, що виправити.

### Скрін

```bash
npm run add-shot -- --file ~/Downloads/скрін.png \
  --name-ua "Світлана Сологуб" --name-ru "Светлана Сологуб" \
  --niche-ua "Продюсування" --niche-ru "Продюсирование" \
  --ring "8 13 85 8"
```

Скрипт сам скопіює файл під нейтральною назвою, порахує розмір і додасть рядок. `--ring` потрібен, якщо в тексті є жорсткий результат (гроші, цифри). Щоб знайти координати рамки, подивись на скрін: ліва межа, верхня межа, ширина й висота рамки у відсотках. `--position 4` ставить відгук на 4-те місце, без нього він іде в кінець.

### Відео

Спосіб А (відео вже завантажене в Bunny вручну): у Bunny відкрий відео й скопіюй його Video ID.

```bash
npm run add-video -- --id 4f2c1a0e-0000-0000-0000-000000000000
```

Імена й ніші для відео не обов'язкові — на головній сторінці їх не видно. Якщо все ж треба, додай `--name-ua`, `--name-ru`, `--niche-ua`, `--niche-ru`; тоді, якщо в таблиці вже є рядок цієї людини без ID, скрипт заповнить його замість додавання дубля.

Спосіб Б (скрипт сам завантажить файл у Bunny): потрібен ключ у `.env` (див. нижче).

```bash
npm run add-video -- --file ~/Downloads/відео.mp4
```

Вимоги до відео: вертикальне 9:16 (Reels), до 2 хвилин, mp4. Bunny закодує його сам, на це потрібно 1–3 хвилини після завантаження.

### Промпт для Claude Code

> Додай у reviews-landing відгук. Відео: файл `~/Downloads/babich.mp4`, імʼя Анна Бабіч / Анна Бабич, ніша Системний блогінг / Системный блогинг. Постав його на 5 місце. Після цього запусти `npm run validate`, закоміть і запуш.

## Відео: як воно працює і чому так

• Плеєр власний, без інтерфейсу Bunny, YouTube чи Диска. З сайту немає жодного посилання назовні, окрім кнопки на `vyschaliga.com/main`.
• Назва відео ніде не показується. У Bunny відео називається нейтрально (`review-…`), а імʼя людини береться лише з таблиці.
• **Телефон:** відео, яке опинилось на екрані (видно щонайменше 60%), запускається саме **без звуку** і ставиться на паузу, коли відвідувач гортає далі. Грає лише одне відео за раз. На відео є лише маленька іконка звуку: тап вмикає звук, і він лишається увімкненим на наступних відео.
• **ПК:** автозапуску немає. На відео одна золота кнопка: клік запускає відео зі звуком, повторний клік ставить на паузу.
• Звук від кнопки гучності телефона браузери сайту не передають, тому керування звуком зроблене іконкою.
• Якщо браузер забороняє автозапуск (режим економії батареї, вбудовані браузери Telegram/Instagram), на телефоні замість нього з'являється золота кнопка запуску.
• Відео завантажується лише тоді, коли його видно (телефон) або коли натиснули кнопку (ПК), тому трафік не марнується.

## Налаштування Bunny (разово, вже зроблено)

• Stream → бібліотека `reviews.vyschaliga.com` (Library ID `786703`, CDN `vz-b6304f2b-1be.b-cdn.net`; ці значення вже в `public/config.js` і `vercel.json`).
• Security → у дозволених доменах (Allowed referrers) стоїть `reviews.vyschaliga.com`: інші сайти не зможуть вбудувати наші відео.
• Premium encoding і Transcribing вимкнені (не потрібні).
• Якщо CDN-адреса колись зміниться, її треба замінити у двох місцях: `public/config.js` і `vercel.json` (рядок із Content-Security-Policy).

## Ключ Bunny (потрібен лише для способу Б)

1. У Bunny: Stream → бібліотека → **API** → скопіюй **API Key**.
2. У корені проєкту: `cp .env.example .env` і встав ключ у `BUNNY_API_KEY=`.
3. Файл `.env` у GitHub не потрапляє (він у `.gitignore`). Ніколи не вставляй ключ у код, у README, у `config.js` і в чати.

Сайту ключ не потрібен: плеєр користується лише публічною CDN-адресою.

## Запуск на комп'ютері

```bash
npm run dev          # відкриється на http://localhost:3000
npm run validate     # перевірка таблиці
```

Node 18 або новіший. Залежностей немає.

## Деплой на Vercel (разово)

1. Vercel (організація `Vyshcha Liga`) → Add New Project → імпортуй цей репозиторій з GitHub. Налаштування підтягнуться з `vercel.json` (Build Command `node scripts/validate.mjs`, Output Directory `public`), Framework Preset: Other.
2. Settings → Domains → додай `reviews.vyschaliga.com`.
3. У DNS домену `vyschaliga.com` створи запис, який покаже Vercel: зазвичай `CNAME` для `reviews` на `cname.vercel-dns.com` (точне значення Vercel покаже на сторінці Domains).
4. Перевір сайт і в Bunny → Security переконайся, що домен у дозволених.

Кожен push у `main` оновлює сайт автоматично.

## Збільшення скріна (ПК)

На ПК клік по скріну плавно збільшує його до центру екрана (фон затемнюється й розмивається). Повернення: клік у будь-яке місце, клавіша Esc або прокрутка. На телефоні функції немає, відео не збільшуються. Код: `openZoom` / `closeZoom` у `public/app.js`, стилі `.zoom-*` у `public/styles.css`.

## Версія

Одна сторінка (`/`): стіна без імен і ніш (клас `nonames` на `<html>`). Тестову версію з підписами (`/v2`) прибрано. Імена й ніші в таблиці не обовʼязкові.

## Блок досягнень

Чотири буліти під сірою лінією на першому екрані (тексти: ключі `s1n…s4c` у `DICT` в `public/app.js`, UA/RU).
• ПК: смуга з 4 колонок на всю ширину (на 601–1100 px — 2×2).
• Мобільна (≤600 px): скляні картки з блюром, що безперервно рухаються справа наліво. Карусель нескінченна (набір клонується, зсув береться за модулем довжини), її можна гортати пальцем з інерцією; на паузу ставиться поза екраном і при `prefers-reduced-motion`. Код — `initStats()` в `public/app.js`.

## Шрифти

Фірмові шрифти бренду (Eurostile Condensed, TT Commons Pro) віддаються з Adobe Fonts і прив'язані до доменів. Для `reviews.vyschaliga.com` доступу немає, тому зараз стоять найближчі безкоштовні: Oswald (заголовки) та Onest (текст). Якщо з'явиться доступ, шрифти міняються в `public/styles.css` (блок `@font-face` і правило `.d`).

## Безпека

• Жодних секретів у репозиторії: ключ Bunny лише в локальному `.env`.
• Заголовки в `vercel.json` дозволяють завантаження лише з нашого домену й нашої CDN. Це заодно блокує будь-яке випадкове посилання на сторонній сайт.
• Захист від вбудови відео на чужих сайтах: Allowed referrers у Bunny.

## Нескінченна стрічка на телефоні
На екрані ≤520px, коли до низу лишається ~3 екрани, дописується ще одна порція відгуків, починаючи з 2-го
(перший під заголовком не повторюється, перший екран більше не з'являється). Стрічка не має кінця і не залежить
від кількості відгуків; кодом нічого не телепортується, тому скрол не смикається. У DOM тримаються лише
2 останні порції (старіші замінюються порожнім блоком такої ж висоти). На ПК/планшеті нічого не змінюється.
Код: `initLoop()` у `public/app.js`.

## Версія для ретаргету: /rtg
Той самий ленд за адресою `/rtg` (rewrite у `vercel.json`, закрита від індексації). Кнопка «Хочу у Вищу Лігу» відкриває
попап-анкету (`public/rtg.js` + `public/rtg.css`, підтягуються тільки на /rtg), фон блюриться як під кнопкою. Мова питань = мова ленда (UA/RU).
На телефоні попап компактний: підписи всередині полів (зсуваються вгору при введенні), роль — «таблетки» з галочкою;
«@» у ніках підставляється сам, Enter веде до наступного поля.
Роль — множинний вибір (у таблицю через «, », напр. «Продюсер, Эксперт»); «Поки не в інфобізнесі» знімає інші варіанти і навпаки.
Після відправки: конфеті (чорне/золоте/біле), «Ваша анкета прийнята» і кнопка в канал передзапису (https://t.me/+khBdwlzmHHBhNzIy,
той самий, що в анкеті на Tilda). Відгуки/відео на /rtg і на основному ленді спільні.

Куди йдуть відповіді: `POST /api/lead` (`api/lead.js`) → Google Apps Script (`scripts/apps-script/Code.gs`) → рядок у таблиці «Анкети з Tilda - ВЛ 60» (Лист1), куди пише й Tilda; звідти він сам з'являється в «Анкета предзапису» і «БД заявок»
(колонки підбираються за назвами в 1-му рядку; formid = rtg). У «Анкета предзапису» писати НЕ можна: там формули IMPORTRANGE.
Потрібні змінні у Vercel (Settings → Environment Variables): `SHEETS_WEBHOOK_URL` (адреса веб-застосунку, що закінчується на /exec)
і `SHEETS_SECRET` (такий самий рядок, як `SECRET` у Code.gs). Після додавання змінних — Redeploy.
